# 3-minute demo script

1. Start at Dashboard.
2. Say: "Patients receive discharge summaries that are clinically accurate but difficult to follow."
3. Click Create Care Plan.
4. Load the sample document.
5. Choose English/Kannada/Hindi.
6. Generate.
7. Show:
   - medicine cards
   - frequency/duration/timing
   - warning signs
   - follow-up
   - questions for doctor
8. Click Set reminders.
9. Create a dose reminder.
10. Explain:
   "Our key safety principle is that CareBridge simplifies the doctor's document; it does not prescribe or change it."
11. If asked about AI:
   "Gemini is used for extraction and patient-friendly structuring. A deterministic fallback keeps the demo functional if the API is unavailable."
